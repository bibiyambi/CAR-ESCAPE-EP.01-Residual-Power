# 잔류 전원 · 3막 통합 플레이어블 v2.1

M-04의 차량 밀실에서 시작해 감시실의 조작 기록을 복원하고, 준비해 둔 흔적으로 프레임과 시설 출구를 여는 미스터리 게임입니다. 첨부된 `잔류전원_3막_통합개발설계서_v2.0.docx`를 기준으로 P01–P15를 연결했습니다.

## 실행

- 별도 제공된 `잔류전원_플레이어블.html`은 이미지·폰트·음향을 포함하는 단일 파일입니다. 다운로드한 뒤 Chrome/Edge 등 최신 브라우저에서 열어 주세요. 큰 파일이므로 첫 표시까지 잠시 걸릴 수 있습니다.
- 소스팩에서는 압축을 모두 푼 뒤 `index.html`을 열면 됩니다. 파일 옆 `assets` 폴더를 유지해 주세요.
- `에셋도감.html`에서 배경·아이템·문서·흰색 윤곽 마스크·음향을 개별 확인할 수 있습니다.
- 실행 중 인터넷 요청이나 실제 메시지 송신은 하지 않습니다. 음성도 파일에 들어 있습니다.

## 플레이

화면의 물건을 터치해 조사합니다. 소지품 1개는 대상에 사용하고, 2개는 조합할 수 있습니다. 수첩에는 발견한 단서가 남습니다. 작은 물건이 누르기 어려우면 일시정지 메뉴의 **현재 화면 조사 목록**을 이용하세요. 조사 영역 표시는 물건과 영역의 윤곽 안쪽에만 은은한 흰빛을 표시합니다.

**화면 조작 보조 ON**이 기본입니다. 와이퍼 정지/작동, 풍량 낮음/중간을 게임 전용 입력으로 생성합니다. 단말기를 먼저 조사한 뒤 각 상태를 0.7초 유지합니다. 입력 패널에는 값과 수신 상태만 있고, 해법은 장면의 문서·녹음·각인에 있습니다. 같은 상태 반복은 다음 단계로 세지 않습니다. 잘못 입력하면 현재 순서만 초기화됩니다.

가방 끈·서랍·룸미러·오디오 믹서·시트·선루프·스마트키·시동은 모두 게임 오브젝트입니다. 현실의 벨트를 풀거나 좌석·미러·선루프·시동을 조작할 필요가 없습니다. 구조 명단 송신과 차량 이동도 게임 내부 연출입니다.

## 구현 범위

| 항목 | 현재 제공 |
|---|---|
| 본편 | 3막, S01–S14, P01–P15, 최종 탈출·명단 접수·윤서 메시지 |
| 이미지 | 기존 차량 아트 유지, 시설·귀환·엔딩·CCTV 11장 추가, 투명 아이템 5개 추가 |
| 퍼즐 | 물건 조사·조합·접기·각도·스테레오 분리·입력 순서·영상 정렬·장부 대조·문서 매칭·회로 공통점·경로 비교 |
| 저장 | schemaVersion 2, 1막 v1 기록 이동, 손상 저장 보호와 백업 |
| 화면 | 원본 장면 contain 배치, 별도 UI, 12개 앱 창 프리셋, 글자 100/130/150% |
| 정차 | 개발용 빌드는 명시된 모의 정차 신호. 실차 빌드는 호스트 검증 신호 필요 |
| 실제 차량 연동 | 읽기 전용 어댑터 계약과 검증 차단 구현. 네이티브 SDK 연결·권한 요청·실차 검증은 미완료 |

**OFF는 아직 실제 차량에서 구동 검증된 기능이 아닙니다.** 연결·권한·차종별 값 매핑·실제 정차 신호가 없는 HTML에서는 OFF 전환을 거부하고 이유를 보여 줍니다. 가짜 연결이나 자동 성공으로 바꾸지 않습니다. `IMPLEMENTATION.md`에 실제 앱에서 연결할 읽기 전용 호스트 계약을 적었습니다.

45–60분은 v2 설계 목표입니다. 이번 검사는 정답을 아는 상태의 기능 검증이며 실제 사용자 플레이 시간이나 난이도 검증 결과가 아닙니다. 시간 제한은 없습니다.

## 파일 구성과 재빌드

- `engine.js`: 1막 물건 조작 규칙. `engine-v2.js`: 통합 상태·입력 세션·나머지 퍼즐·이전 저장 이동.
- `source/act1-app.js`: 기존 렌더러 보존본. `source/v2-app-extension.js`: 3막 단말기·입력 UI·엔딩. `app.js`: 이 둘을 통합한 실행본.
- `style.css`, `style-v2.css`: 차량 프레임과 기록실 디자인.
- `assets/backgrounds`: 배경 PNG. `assets/items`: 원본 투명 PNG. `assets/cutouts`: 원본 PNG를 정확한 윤곽으로 클리핑한 게임용 SVG.
- `assets/alpha`, `assets/masks`: 흰색 실루엣 PNG/SVG. `assets/documents`: 정확한 글자·도면 SVG와 PNG.
- `assets/audio`: 한국어 합성 대사와 게임 효과음. `assets/fonts`: 폰트와 라이선스.
- `validation`: 이번 버전 규칙 검사와 화면 확인 기록.

소스 변경 후 `python tools/upgrade_ui.py`, `python tools/build.py` 순서로 실행합니다. 빌더 자체는 Python 표준 라이브러리만 사용합니다. `index.html`과 `standalone.html`을 다시 만듭니다. 규칙 검사는 `node validation/v2-rules.test.cjs`입니다. 아트 재내보내기 도구는 별도 `tools/requirements-art.txt` 의존성이 필요합니다. `regenerate_vectors.py`는 보존된 1막 제작 원본이므로 통합 버전에서 단독 실행하지 마세요. 새 문서/마스크는 `v2_vectors.py`를 사용합니다.

프롬프트와 생성 이력은 `ASSET_PROMPTS.md`, `source/v2-art-provenance.json`에 있습니다. 원본 생성 PNG는 수정하지 않고 보존했습니다.

## v2.1 보완

- 상태를 잠깐 바꿨다가 원래 값으로 되돌린 경우 0.7초 유지로 오판하던 문제를 수정했습니다. 잘못된 시각·누락 시각·이전 단말 이벤트를 구분합니다.
- 메뉴·연결 중단에서 미완료 유지 시간을 버리고, 재개 후 새 입력만 받습니다. 화면을 옮기면 이전 단말 입력은 해제합니다.
- 입력 패널에는 현재 장치의 조작만 표시하며, 장치를 활성화하지 않았을 때는 안내를 표시합니다. ‘단서 화면으로 돌아가기’로 결과를 조사할 수 있습니다.
- L/R 원문은 각각 읽는 즉시 수첩에 남습니다. 마지막 시동 실패는 실제로 남은 준비 단계만 알려 줍니다.

기존 17개 규칙 검사와 v2.1 추가 회귀 검사 11개를 실행했습니다. 상세 결과는 `validation/v21-regressions-report.json`에 있습니다. `v2-browser-report.json`은 이전 v2 전편 화면 검증 기록이며, 이번 수정의 화면 검증은 별도 v2.1 기록을 확인하세요.
