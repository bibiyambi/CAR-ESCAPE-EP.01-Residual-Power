# v2.1 · 2026-11-11

짧은 조작이 안정 입력으로 잘못 이어지는 문제와 잘못된 입력 메타데이터 처리를 보완했습니다. 메뉴 정지와 장면 이동 때 입력 세션을 분리하고, 현재 단말의 조작만 표시합니다. 입력 패널에 단서 화면 복귀 버튼을 추가했습니다.

L/R 원문은 읽는 즉시 각각 수첩에 남습니다. 마지막 시동에서는 빠진 확인 단계만 안내하고, 이미 확인한 키/토큰 버튼은 완료 상태로 표시합니다. 저장 형식은 schemaVersion 2를 유지합니다.

검증: 기존 규칙 17개 + 회귀 11개 통과. 브라우저에서 입력 패널·단서 복귀·장면 이탈·메뉴 재개·미지원 OFF 차단·저장 복원과 12개 화면 크기를 확인했습니다. 이전 v2의 전편 15/15 UI 검증 기록과 이번 v2.1 범위는 보고서에 구분했습니다.

이미지·퍼즐 해법·3막 구성은 유지했습니다. 실차용 네이티브 SDK 바인딩 및 실제 차량 검증은 별도 작업입니다.
